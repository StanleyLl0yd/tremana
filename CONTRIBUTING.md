# Contributing to TreMana

Contributions and bug reports are welcome.

## Development principles

- Keep the application native to macOS.
- Prefer standard Apple frameworks.
- Use stable, supported dependencies.
- Maintain compatibility with documented RPC versions.
- Never silently ignore unsupported server operations.
- Add tests for changes in observable behavior.
- Avoid unrelated refactoring in focused changes.

## Pull requests

- Explain the purpose and scope.
- Document compatibility implications.
- Include tests where applicable.
- Keep changes small enough to review.

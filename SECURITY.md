# Security Policy

TreMana handles remote Transmission connections
and potentially sensitive authentication credentials.

## Reporting

Please do not publicly disclose credentials,
tokens, or sensitive vulnerability details.

Use GitHub private vulnerability reporting when
available. Otherwise contact the maintainer privately
before publishing security details.

## Security expectations

- Keep dependencies current.
- Do not disable TLS validation.
- Do not store credentials in plaintext.
- Do not include secrets in logs or issue reports.

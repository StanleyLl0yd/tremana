# TreMana

**Нативный клиент для удалённого управления Transmission на macOS.**

[English](README.md) · **Русский**

Управляйте торрентами на роутере, NAS или другом устройстве с **Transmission** прямо с Mac — в компактном и быстром приложении с привычным интерфейсом macOS.

## Возможности

- **Всё на виду:** прогресс, скорости, ETA, рейтинг, сиды, личеры и настраиваемые столбцы с изменением порядка.
- **Управление торрентами:** добавление magnet и `.torrent`, запуск, пауза, проверка целостности, переанонс и удаление; удаление файлов на сервере требует подтверждения.
- **Подробная информация:** файлы, трекеры, пиры и веб-сиды в панели с изменяемой высотой.
- **Безопасное подключение:** профили серверов с сохранением паролей в связке ключей macOS, поддержка HTTPS.
- **Нативная работа:** SwiftUI, системное оформление, адаптивное автообновление, без сторонних UI-фреймворков.

<sub>Выбор отдельных файлов для загрузки и Move/Rename пока в разработке. Последовательная загрузка частей недоступна через Transmission 3.00 RPC 16.</sub>

## Скачать

**[Скачать TreMana 0.1.0 для macOS — ZIP](https://github.com/StanleyLl0yd/tremana/releases/download/v0.1.0/TreMana-v0.1.0-macOS27-arm64.zip)**

**Требуется:** macOS **27 или новее**, Mac с **Apple Silicon (arm64)** и доступный сервер Transmission (проверено с **3.00 / RPC 16**).

Распакуйте архив, перенесите `TreMana.app` в «Программы» и запустите. Версия 0.1.0 подписана **ad-hoc, без нотарификации Apple**. При первом запуске macOS может запросить разрешение в **Системных настройках → Конфиденциальность и безопасность**. Отключать Gatekeeper целиком не нужно.

Не открывайте RPC-порт Transmission в публичный интернет. Предпочтительны HTTPS или доверенный VPN; обычный HTTP — только в доверенной локальной сети.

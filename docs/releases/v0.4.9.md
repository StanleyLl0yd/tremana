# TreMana v0.4.9 — fit windows to their full measured content

Regular signed Apple Silicon release for macOS 27 and later. Published releases remain immutable.

## Changes

- **Connection and Settings windows** now lay out the full form normally and
  measure its natural height, rather than keeping it inside an always-present
  ScrollView. No controls, fonts or spacing are made smaller.
- When you change language, open/close Connection settings, switch Adaptive/Fixed
  refresh mode, or reveal validation messages, the window recalculates and
  grows/shrinks to fit the complete visible content.
- Scrolling appears only when the measured content is taller than the space
  available in the active display's `NSWindow.visibleFrame`.
- A change in screen geometry triggers a new calculation. Numeric geometry
  diagnostics are logged under `com.sl.tremana / window-sizing` without RPC
  endpoints, usernames or passwords.
- Preserve the compact saved connection from v0.4.8, existing controls,
  password storage, signing identity, transmission functionality, and
  remembered torrent inspector.

## Hardware acceptance

1. Open a saved connection: compact view should fit with no scrollbar.
2. Expand Edit connection: the window must grow to include the entire form.
   It can scroll *only* if the expanded form exceeds the usable display height.
   Collapse and confirm the window shrinks again.
3. Open Settings: all controls visible without scrolling if they physically fit.
   Switch Adaptive/Fixed, check interval picker and automatic resizing.
4. Switch RU/EN and system/light/dark. Test both normal and small display sizes.
5. Verify no regression to v0.4.6 crash hardening, connection, Keychain,
   torrent inspector, and file operations.

If a window still unexpectedly scrolls, inspect Console for subsystem
`com.sl.tremana` and category `window-sizing`, including measured content
height, actual/target content height, visible frame, and the overflow decision.

CI checks Swift tests, localization and release signing. Exact real-device
window geometry and final repository-wide audit remain pending.

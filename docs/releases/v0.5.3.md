# TreMana v0.5.3 — quieter file updates and remembered columns

Regular signed macOS 27 Apple Silicon release. v0.5.2 remains unchanged.

## Changes

- File and folder Download/Priority cells now compare only the values that affect
  their own presentation. Unchanged cells consume immutable row snapshots and
  are wrapped in EquatableView, so a verified detail refresh does not need to
  redraw every control in both columns.
- During an RPC mutation the file table temporarily blocks pointer interaction
  without applying the global disabled appearance to every checkbox and priority
  menu. The changed file and folders whose aggregate state changes are the only
  controls expected to visibly update.
- User-resized widths are saved independently for the torrent list and file
  inspector. Widths are keyed by stable column identifiers, restored at table
  attachment, and stored locally in UserDefaults.
- Existing main-list column visibility and ordering customizations remain in
  SceneStorage and are not replaced by width preferences.
- English and Russian header fallbacks are included for width restoration.
- No changes to Transmission RPC semantics, Keychain, strict file queue,
  selected-file safety checks, or the v0.5.2 skipped-state behaviour.

## Acceptance

1. Toggle one file: only its Download/Priority cells and affected folder
   aggregates should visibly change; unrelated controls must not dim or flash.
2. Repeat on a folder and with batch actions.
3. Resize columns in the torrent list, quit TreMana, relaunch, and confirm widths
   are restored.
4. Independently resize file-inspector columns, switch inspector tabs and
   relaunch; confirm widths are restored without affecting the torrent list.
5. Repeat in English and Russian, and after hiding/reordering torrent columns.
6. Confirm no regressions to skipped-state display, saved file priority,
   strict queue protections, and last-wanted-file guard.

The final signed release is produced only after exact-head macOS 27 build,
tests, package verification, stable Code Signing requirement check, and
release-tag verification. Hardware acceptance remains pending.

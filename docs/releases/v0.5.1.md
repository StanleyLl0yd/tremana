# TreMana v0.5.1 — consistent file selection and visible app version

Regular signed macOS 27 Apple Silicon release. v0.5.0 remains unchanged.

## Changes

- File rows and folder rows now use the same custom-drawn selection control.
  Checked, unchecked, mixed and unknown states share one 17 pt square, one
  32 × 28 pt hit target, identical geometry and stable accent colors.
- The control no longer mixes a native macOS checkbox Toggle for files with a
  separate SF Symbols button for folders. Checked states remain consistently
  blue when the main window is inactive; mixed folders have a distinct dash.
  Disabled states still reflect real constraints such as an active operation,
  strict queue lock, unknown metadata, or attempting to skip the last wanted file.
- The app version is restored to the bottom status bar as `TreMana 0.5.1`,
  alongside the connected Transmission version. The duplicate sidebar-only
  version label is removed.
- Existing file/folder batch operations, RPC indices, accessibility labels,
  and localized English/Russian UI are preserved.

## Acceptance

1. Compare file and folder selection controls in the active and inactive window.
   Their geometry and selected accent color must match.
2. Verify checked, unchecked and mixed folder states.
3. Verify disabled behavior for strict file queue, busy state, unknown metadata,
   and the last remaining wanted file.
4. Verify the bottom bar shows both TreMana and Transmission versions.
5. Verify English/Russian localization and existing tree selection operations.

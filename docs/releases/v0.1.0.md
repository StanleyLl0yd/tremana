# TreMana 0.1.0 — first public GitHub release

Native Transmission remote manager for macOS 27+ and Apple Silicon (arm64).

## Shipped
- Saved Transmission profiles with passwords in macOS Keychain; RPC 16 / Transmission 3.00 support.
- Torrent list, adaptive automatic refresh, configurable/reorderable/hideable columns.
- Rich read-only torrent inspector: Details, Files, Trackers, Peers and Web Seeds.
- Magnet and torrent file additions; Start, Start Now, Pause, Verify piece hashes, Reannounce and Copy Magnet.
- Safe Remove Torrent with separate confirmation for keeping or deleting server files.
- Native SwiftUI controls, system settings and Cmd+R manual refresh.

## Limitations
- Apple Silicon arm64 and macOS 27+ only.
- Built in GitHub Actions with an ad-hoc code signature; not Developer ID signed or Apple notarized. macOS may ask for one-time authorization in System Settings > Privacy & Security. Do not disable Gatekeeper globally.
- File-selection editing remains planned (#23); Move/Rename on the remote server remains planned (#27).
- Strict autonomous file queue is not yet implemented; Transmission 3.00 RPC does not expose sequential piece downloading.
- Compatibility beyond Transmission 3.00 / RPC 16 requires independent verification.

## Verification
Release CI rebuilds and tests the exact protected-main commit, checks the signed bundle and architecture, publishes the macOS ZIP plus SHA-256 file, then downloads the published ZIP and compares its bytes.

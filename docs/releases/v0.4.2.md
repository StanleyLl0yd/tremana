# TreMana 0.4.2 — macOS 27 acceptance patch

Test build for Apple Silicon and Transmission 3.00 / RPC16. This is not final hardware acceptance.

- **More room for files.** The vertical resizable split now prefers a compact torrent
  list and a substantially taller inspector. The file Table fills the available
  inspector area and expands with the window; the split divider remains draggable.
- **Native right-click file actions.** Removed the separate "Selected file actions"
  menu. Use Command/Shift multi-selection and the Table's contextual menu for
  Download, Skip, Low, Normal and High priority. The last-wanted-file protection
  and server-side selection validation are unchanged.
- **Keychain access scope.** New and replaced RPC passwords get a macOS
  file-based Keychain ACL that trusts only the running, consistently signed
  TreMana app. Existing legacy items are kept intact and may need one
  **Always Allow** authorization or a password re-save; this is not guaranteed
  to solve every machine-specific prompt without on-device verification.
- The signing identity, bundle identifier, Keychain service/account identifiers,
  strict file queue behavior and prior published releases are unchanged.

## Acceptance checks

1. Resize the window, drag the horizontal split, verify the file list uses
   all remaining lower-pane height and remains scrollable.
2. Command/Shift-select several files. Right-click a selected row and apply
   a group action. Repeat with a single row and an unselected row.
3. Verify exact affected file indices via an independent Transmission client,
   including refusal to exclude the last wanted file.
4. Open a saved connection after upgrading. Select **Always Allow** if macOS
   requests legacy Keychain permission. Quit/relaunch and verify no recurring
   prompt; repeat after the next independently signed build.
5. Verify connection/disconnection, Command+, and light/dark layout.

CI can prove compilation, model-level RPC safety, and stable signing
requirements. Only actual macOS/Keychain hardware testing can establish
prompt-free upgrades. Full repository-wide audit remains outstanding.

# TreMana v0.4.10 — final bottom-edge allowance for connection editor

Regular, signed macOS 27 Apple Silicon release. Existing releases are not changed.

## Change

The compact saved connection and Settings window are unchanged and already passed
Mac hardware acceptance in v0.4.9. The expanded Connection editor had its final
RPC row too close to the bottom of the frame on macOS 27.2.

When sizing the Connection window, reserve an additional 20 points beyond the
measured SwiftUI form height to account for NavigationStack layout not included
in the form's geometry. No UI control, font, row spacing or in-form padding is
reduced. Changes in language, error messages or editor visibility still trigger
the measurement and automatic window resizing. If the required form height is
larger than `NSWindow.visibleFrame`, use scrolling rather than clipping.

Settings, compact Connection layout, Keychain, Transmission RPC, connected window
and inspector behavior are unchanged.

## Mac acceptance

1. Expand Edit connection and verify the final HTTP row has a visible bottom
   margin like Settings. Collapse and confirm compact form stays compact.
2. Confirm changing the interface language adjusts sizes without truncation.
3. On a small screen, verify the full expanded form is reachable by scrolling,
   without controls disappearing behind the window border.
4. Verify Settings remains correct, Connect works, and no Keychain prompts
   or SwiftUI crash regressions are introduced.

CI runs unit tests, Swift build, localization and signing validation. A final
repository-wide audit and hardware acceptance remain separate milestones.

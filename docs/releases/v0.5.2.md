# TreMana v0.5.2 — explicit skipped state and no inspector flash

Regular signed macOS 27 Apple Silicon release. v0.5.1 remains unchanged.

## Changes

- An unchecked file is now shown as **Skipped**, not as Normal priority.
  A folder with no wanted descendants is also Skipped; a folder with a mix
  of wanted and skipped descendants is Mixed.
- The Transmission file priority is retained when a file is skipped. Re-enabling
  the file restores its previous Low/Normal/High priority without another RPC
  priority mutation. Priority controls for skipped items show the effective
  Skipped state; the Download checkbox remains the direct include/exclude action.
- The same effective summary is used in the torrent list priority column.
- File selection, priority and folder batch mutations no longer set the selected
  inspector detail to nil while waiting for Transmission to verify the change.
  The existing inspector remains mounted with its current data, then the verified
  detail snapshot replaces it. No whole-inspector loading screen during a toggle.
- Added regression coverage for all-skipped/mixed folder summaries and a held
  post-mutation RPC response that proves the inspector snapshot remains available.
- No change to Keychain, RPC endpoints, file indices, folder tree, UI sizing,
  or protected main.

## Acceptance

1. Uncheck a file: Download becomes off and Priority displays Skipped.
2. Re-enable it: Download becomes on and the previously selected priority returns.
3. Check a folder with all children skipped, a partially skipped folder, and a
   folder with every child selected.
4. Toggle one file while watching the inspector: only the affected checkbox
   and aggregate folder states should change after RPC confirmation. The
   inspector must not flash, disappear, show a spinner, or rebuild its tabs.
5. Repeat in active and inactive window states and in RU/EN.
6. Verify batch selection and strict queue protections.

CI runs Swift tests, localization validation, source guards, app build and
signed release packaging. Hardware acceptance and the final repository-wide
audit remain pending.

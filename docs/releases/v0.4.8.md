# TreMana v0.4.8 — genuinely compact connection and Settings

Regular signed macOS 27 / Apple Silicon Release. All previously published versions stay immutable.

## Changes

- **Saved connections:** the disconnected window now opens in a compact state:
  Connect, the saved-profile picker and the selected server address. The RPC
  URL, credentials, Remember toggle, profile name and Forget action remain
  available behind **Edit connection**. Choosing a custom/new connection
  automatically reveals the form. This is *progressive disclosure*, not removal
  of any settings; passwords still stay in macOS Keychain and are read only
  after explicit Connect.
- **Settings:** removed an oversized, read-only "Refresh behavior" block that
  was forcing scrolling and window-height clamping even on normal screens.
  Timing details remain in the Refresh mode control's tooltip. Language,
  theme, toolbar preference, refresh enable/mode and fixed interval remain.
- **Window sizing:** the disconnected window now targets 660 points wide and
  at least 260 points tall, while Settings targets 530 points wide and at
  least 300 points tall. The main connected window keeps the native resizable
  layout and its remembered geometry. Windows continue to grow with visible
  options and validation errors and never exceed the screen's visible frame.
- Both auxiliary windows remain non-user-resizable; overflowing content
  remains scrollable only where the physical display is too short.
- Two additional regression tests exercise compact minimums, expansion and
  screen-bound clamping. EN/RU strings are updated.

## Mac hardware checks

1. Open with an existing saved profile. The Connection window must show only
   a compact profile summary and the Connect action, **no scrollbar**.
2. Click Edit connection. Confirm all RPC fields and the HTTP warning are
   available, then hide them; the window must grow/shrink appropriately.
   Choosing Custom connection also reveals editing automatically.
3. Open Settings with Command+,. All active controls should fit without
   scrolling at a normal display height. Choose Fixed refresh mode to reveal
   the interval selector and switch back to Adaptive.
4. Switch RU/EN and light/dark while inspecting dimensions and text.
5. Check that a genuinely small display may scroll without cutting off
   controls; connected torrent window must still be user-resizable.
6. Confirm no regression to v0.4.6 crash hardening, Keychain permissions,
   sidebar preferences, file context menu, saved inspector tab and split size.

CI verifies compilation/unit tests and signing, not actual screen geometry.
Hardware acceptance and final repository-wide audit remain pending.

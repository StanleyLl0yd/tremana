# TreMana v0.4.5 — content-sized macOS windows

Native macOS 27 / Apple Silicon test release for Transmission 3.00 / RPC 16.

## What changed
- The disconnected connection form is an intrinsically measured compact layout,
  not a full-height grouped Form with an unnecessary scrollbar. Profile,
  credentials and action controls remain visible. Its window is not manually
  resizable but automatically adjusts to translated text, errors and profile
  state. A shorter display limits height, retaining scrolling as a fallback.
- The Settings window also measures its actual content, including the
  conditional fixed-refresh interval selector. It automatically grows/shrinks
  as needed (within screen bounds), instead of cutting off controls at 505 pt.
- The torrent toolbar no longer has the enormous gap after the server name.
  The separator is a fixed 1-pt line; the profile name takes only the
  natural width it needs, and controls use tighter spacing.
- Connected torrent-window resizing, inspector split and last tab persistence,
  burgundy appearance, Keychain ACL and credentials behavior are retained.

## Acceptance checklist (real macOS 27)
1. On a normal-sized display, open TreMana disconnected: all RPC fields, the
   connection button and local-HTTP permission must be visible without a
   vertical scrollbar. The window must not be manually resizable.
2. Change saved profiles, toggle Remember, enter an invalid URL and press
   Connect: any error may grow the window automatically without clipping.
3. Use **Command+,**. In normal adaptive refresh mode, all Settings sections
   including the last note must be visible without manual resizing/scrolling.
4. Switch Refresh mode to Fixed. The extra Update interval row should cause
   automatic window growth. Switch back and check that the window shrinks.
5. Verify long Russian labels and light/dark mode do not clip fields; on a
   genuinely smaller display only, scrollable overflow is acceptable.
6. Connect and check compact spacing between sidebar toggle, Disconnect,
   server name, separator, Add, Start and Pause. All icon-only toolbar settings
   must still apply.
7. Confirm the previous file-tab, pane-size and secure saved-profile behavior
   survive updating over v0.4.4.

The exact-head CI verifies compilation, protocol tests and packaging. The
signed release workflow verifies certificate and the stable designated
requirement. Hardware acceptance and repository-wide audit remain pending.

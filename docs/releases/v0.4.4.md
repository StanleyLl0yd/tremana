# TreMana 0.4.4 — compact macOS windows and remembered layout

Signed macOS 27 / Apple Silicon test release, for real-device acceptance on Keenetic
Transmission 3.00 / RPC16. This build does not claim final milestone acceptance.

## Interface
- The disconnected screen no longer creates a pointless empty sidebar or a
  large "Show Sidebar" strip. It uses a compact dedicated window size with an
  inline Connection hero and Connect action. Connecting restores the remembered
  full torrent-window size; disconnecting remembers that size before compacting.
- The connected sidebar starts hidden; its toggle is a small **icon-only**
  button regardless of the toolbar label preference. The sidebar remains
  available for filtering torrents.
- **Disconnect** now uses the same toolbar presentation as Add, Start and Pause.
  Selecting "Icons only" removes its caption too; hover help and accessibility
  labels remain available.
- Settings use the same soft burgundy glass tint, deliberately 28% quieter than
  the main window, in dark and light appearances.

## Remembered inspector layout
- The inspector's last selected tab is stored in local user preferences and
  restored on application relaunch, including the Details tab.
- Dragging the horizontal divider changes the torrent/inspector proportion.
  The fraction is saved at the end of a drag and restored on relaunch; the
  layout adjusts to window resizing and keeps both panes usable.
- Stored layout state does not include any password or RPC credential.

## Test on the Mac
1. Open disconnected: verify compact window, no sidebar and no show-sidebar bar.
   Connect and verify full torrent window returns. Disconnect and repeat.
2. Select "Icons only": Disconnect, Add, Start and Pause have only icons.
   Hover tooltips and VoiceOver labels still describe them.
3. Select Details, drag the divider, quit the app completely and relaunch;
   connect and verify both tab and proportion are retained.
4. Open Settings with Command+, in dark and light themes: tinted glass should
   match the main window without the black opaque form background.
5. Check selecting multiple files and context actions after reconnect; no
   daemon mutation may be caused by a layout gesture.
6. Check Keychain: authorization once after a signed update may happen when
   pressing Connect; it must not occur merely on opening a saved profile.

## Verification boundary
Exact-head macOS CI and signing workflow validate compilation, unit tests,
translations, archive, signature and designated signing requirement. Full
on-device visual acceptance and repository-wide security audit remain pending.

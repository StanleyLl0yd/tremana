# TreMana 0.4.6 — SwiftUI main-thread crash hardening

Regular GitHub Release for macOS 27 and Apple Silicon. Preserves immutable
published v0.4.5 and earlier releases.

## Fixed

- Crash report from a **v0.4.4** process on **macOS 27.2** reported a
  main-thread SwiftUI assertion in `EnvironmentValues.subscript.getter`,
  producing `EXC_BREAKPOINT / SIGTRAP`.
- All views requiring `TreManaModel` now receive the same observable model
  explicitly from the root `TreManaApp`. This includes the torrent table,
  details inspector, file wanted/priority cells, batch context menu and
  connection/add/remote-action sheets. No such view now performs an implicit
  `@Environment(TreManaModel.self)` lookup.
- CI runs a source guard against reintroducing that missing-model risk
  in addition to compiling and testing the exact commit on macOS.

## Verification and limitations

The crash report points to the SwiftUI environment getter but does not
name which particular view lacked the model. Explicit injection eliminates
that entire category of missing-observable-model lookup without weakening
RPC/Keychain security. It is a *targeted mitigation*, not proof that every
possible SwiftUI or macOS runtime crash is gone.

- Existing signed identity, Keychain ACL, bundle identifier, RPC settings,
  file queue, user-defined layout and visual design are unchanged.
- Test updating from v0.4.5 (or v0.4.4), switching connection/disconnection,
  selecting torrents and files, using context menus, changing inspector tabs,
  adding a torrent, opening server move/rename sheets, and opening settings.
- Run the app after connecting and leave it open past the prior 34-second
  crash window. If a crash remains, collect a report from **v0.4.6**, not
  another running copy of v0.4.4 from a mounted image.

Crash tracking: [Issue #53](https://github.com/StanleyLl0yd/tremana/issues/53).
For comparison, check the bundle version in the running app's **About** screen:
the incident in the user-supplied report was from `0.4.4 (9)`, launched from
a mounted volume. Close all old app copies before evaluating this patch.

Full real-device acceptance and repository-wide audit remain outstanding.

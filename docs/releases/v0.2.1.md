# TreMana 0.2.1 — macOS acceptance build

Numeric patch release for user acceptance. It replaces the v0.2.0 test build for evaluation, but does **not** imply M1 hardware acceptance.

## Fixed since 0.2.0
- Clear, prominent **Connect** button in the connection hero area, Enter as the default action, and correct busy/blank-URL disabled state.
- Torrent toolbar is hidden while disconnected. Once connected, Add Torrent is labeled; Start/Pause and Disconnect are compact icon controls with localized tooltips and accessibility labels.
- Eliminated fixed-width icon captions, preventing Russian and English toolbar labels from overlapping.
- Removed duplicate "Torrents" header and title above the list.
- Version in sidebar now always comes from the numeric bundle version.

## macOS 27 test checklist
1. Launch without a connection: verify the main Connect button is visible and Start/Pause are not shown.
2. Use the existing saved profile, connect by mouse and (separately) by Enter. Check connection failures are displayed without hiding the form.
3. Verify toolbar on connected server: Add Torrent, Start/Pause after selecting a torrent, Disconnect, and localizable help when hovering icons.
4. Check narrow (minimum 840 px) and wide window sizes with RU and EN language settings, including collapsed sidebar.
5. Verify file wanted toggles, and **only with a disposable torrent**, Move/Rename on Keenetic (#23 / #27).

## Known limitations
- macOS 27+, Apple Silicon arm64; built in GitHub Actions, ad-hoc signed, **not notarized**. One-time approval may be required in System Settings → Privacy & Security. Never disable Gatekeeper globally.
- Real Keenetic hardware acceptance and a full repository-wide M1 audit remain pending. Strict per-file queue and sequential piece download modes are not implemented.
- The GitHub release is marked prerelease to indicate testing, while the actual version/tag/archive contain digits only: `0.2.1`.

Package includes a SHA-256 checksum and is downloaded and compared byte-for-byte in the release workflow.

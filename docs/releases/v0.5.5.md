# TreMana v0.5.5 — native application icon

Regular signed macOS 27 Apple Silicon release. Published v0.5.4 is unchanged.

## Changes
- Install the approved TreMana icon inspired by the Transmission artwork, with a cloud and red bidirectional arrows to distinguish this remote-control client.
- Supply a native `TreMana.icns` with standard macOS icon sizes, created from a transparent source and bundled before code signing.
- Set `CFBundleIconFile` explicitly so Finder, Dock and the application switcher use the new icon.
- No torrent/RPC behaviour changes. Column-width persistence from v0.5.4 is unchanged. Automatic fit-to-content on divider double-click is **not fixed** in this release.

## Acceptance
1. Install the v0.5.5 ZIP and check that Finder and Dock show the approved cloud-and-arrows icon, including after a full application restart.
2. Verify the icon at small and large Dock sizes, and when switching between windows.
3. Confirm that existing server profiles, saved column widths, file operations, and torrent behaviour are unchanged.
4. Confirm the signed app bundle includes `Contents/Resources/TreMana.icns`.

TreMana is an independent remote client for Transmission; this is not an official Transmission release.

# TreMana 0.4.1 — macOS 27 test build

This is a **user-acceptance build**, not a completed milestone. Native macOS 27, Apple Silicon (arm64), Transmission 3.00 / RPC 16.

## Improvements since 0.4.0

- The **Files** inspector is now a native, width-filling macOS table with independently adjustable columns, rather than a fixed-width strip that left unused space in large windows.
- File rows support native multi-selection with Command-click and Shift-click. Selecting **two or more** files shows a single **Selected file actions** menu with Download, Skip, Low, Normal and High priority operations. No duplicate include/exclude switches.
- Group actions are explicit and confined to the current torrent and selected file indices. Before sending anything to the server, TreMana rechecks the torrent hash, every file path/length, and current wanted/priority state. An empty wanted list is never sent. Results are read back from Transmission, not presumed successful.
- **Disconnect** is a clear, compact labelled button on the toolbar; the server name is separate secondary information. When disconnected, the existing **Connect** button remains on the connection form.
- The redundant sidebar Settings button has been removed. Use standard **TreMana → Settings** or **Command+,** on macOS.
- The existing top torrent table, bottom resizable inspector, permanent Keychain signing identity, accurate Mixed priority summary and ordered-file queue are retained.

## Please verify on your Keenetic

1. Resize from 840×560 to full screen: Files should stretch to available inspector width without leaving a large blank region; drag the divider between the torrent list and inspector.
2. Select multiple file rows using Command/Shift, then Download/Skip and priority actions. Check all affected file statuses through Transmission RPC or a second client, and make sure unrelated files are unchanged.
3. Try selecting every wanted file and Skip: the application must refuse leaving the torrent with no selected files.
4. Test right-click torrent actions and strict file queue independently; the piece-order feature is **not supported** on Transmission 3.00/RPC16 and remains informative only.
5. Check the compact Disconnect control and successful reconnect, the default Command+, Settings shortcut, RU/EN, light/dark, and the new app version shown in the sidebar.
6. Check opening the saved server password from Keychain across the update from 0.4.0.

## Signed artifact

The release workflow builds at its exact numeric version commit, runs Swift tests, uses the pinned TreMana Code Signing identity, verifies its designated requirement, publishes an arm64 ZIP with a numeric name, and downloads it again for byte comparison.

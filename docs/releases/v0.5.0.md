# TreMana v0.5.0 — hierarchical torrent files

Regular, signed macOS 27 Apple Silicon release.

## Changes

- Replace flattened relative paths with a native-looking hierarchical file outline:
  a torrent root, nested folders and individual files.
- Expand/collapse individual folders, expand all, collapse all. Small and medium
  torrents open with their hierarchy expanded; large torrents start with the
  root and first folder level expanded to keep the list navigable.
- Folder and torrent-root rows show aggregate size, completion progress, download
  selection state, and priority summary calculated from descendant files.
- Folder download checkbox reflects wanted / skipped / mixed states. Applying a
  folder action changes only its descendant RPC file indices and preserves the
  rule that at least one file must remain selected.
- Folder priority uses the actual descendant priorities. Mixed is displayed when
  children differ; choosing a priority applies to that folder's files only.
- Multi-selection and the existing context menu continue to operate on file rows
  and now also expand selected folders into their descendant file indices.
- File rows keep their individual wanted toggle, priority picker and progress.
- File-type SF Symbols improve recognition without introducing external
  dependencies or changing Transmission RPC behavior.
- All new controls are localized in English and Russian.

## Safety and compatibility

- Every leaf retains its original Transmission RPC file index. Sorting/indentation
  never changes the index sent to Transmission.
- Tree aggregates are presentation-only. The app continues to use the existing
  verified file mutation and batch RPC paths.
- Strict file queue, Keychain, server-side path operations, connection sizing,
  main torrent list, inspector layout and signing identity are unchanged.

## Verification

CI validates the tree builder, aggregation, path edge cases, Swift 6 build,
localization parity and signed release packaging. Hardware acceptance remains
required for large torrents, multi-selection, folder batch operations and
visual comparison on macOS 27.2.

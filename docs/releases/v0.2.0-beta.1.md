# TreMana v0.2.0-beta.1 — preview for device testing

This **prerelease is not the stable v0.2.0**. It is intended for manual testing on macOS 27+ (Apple Silicon) with Transmission 3.00 / RPC 16 on Keenetic.

## Added since v0.1.0

- Files tab: choose individual files to download with live RPC re-checks and protection against excluding the final wanted file.
- Torrent context menu: server-side **Move Data** to a validated absolute path, with confirmation, and **Rename File/Folder** only for a path reported by the selected torrent.
- Explicit single-torrent IDs, live identity/path re-validation, safe failure reporting, and EN/RU action dialogs.
- Version label `v0.2.0-beta.1` at the foot of the sidebar for this preview.

## Test safely

- Use **disposable test torrents** only. Move/Rename are server filesystem operations and can change or move downloaded data on the Keenetic.
- Verify file selection, path handling, remote permissions, rename of nested folders, unexpected disconnects and the result in another Transmission client.
- Report results in [M1 file-selection #23](https://github.com/StanleyLl0yd/tremana/issues/23) and [server Move/Rename #27](https://github.com/StanleyLl0yd/tremana/issues/27).

## Known limitations

- Neither strict autonomous per-file queueing nor sequential piece mode is implemented. Neither can be emulated with file priority.
- Real Keenetic device acceptance, full repository-wide audit and M1 completion are pending; PR #42 is still a draft.
- This build is **ad-hoc signed**, **not notarized** or Developer ID signed. macOS may require one-time approval in System Settings → Privacy & Security. Do not disable Gatekeeper globally.
- The version shown by macOS Finder is `0.2.0` (Apple numeric bundle version convention); the in-app test label and archive are `0.2.0-beta.1`.

ZIP is for macOS 27+ arm64. Its matching `.sha256` is published alongside it.
